# SPELLSTORM — DAILY CHALLENGES
# One challenge per day, cycling through this list in order. Everyone gets the same challenge (and the same
# shuffled decks, Storm Cloud and Weather) on the same day. Edit freely and send it back.
#
# Each challenge is a block of "key: value" lines. Blocks are separated by a line containing only ---
#
#   title:       name shown to the player
#   you:         your wizard        (derby, eve, abragail, may, omar, bunny, oren, croh)
#   opponent:    the CPU's wizard   (same list, or robot for Robot Boy)
#   cpu:         easy | normal | hard | expert            — the usual difficulties, OR
#                rank N / type X                          — a Ranked-style opponent (rank 1–10, personality type A–J)
#                For Robot Boy use: easy | medium | hard
#   rules:       optional, comma-separated:
#                  long                 Long Match (+50% health, 12 Storm Shards to win)
#                  you_hp +N / -N       change your starting health (and maximum)
#                  opp_hp +N / -N       change the opponent's starting health (and maximum)
#                  you_mana N, opp_mana N, you_power N, opp_power N, you_tier N, opp_tier N, you_shards N, opp_shards N
#                  you_init / opp_init  who starts with the Initiative
#   goal:        win                    win the match any way
#                win_health             win by bringing the opponent to 0 health
#                win_shards             win by collecting Storm Shards
#                win_within N           win within N battles
#                win_above N            win and finish with at least N health
#   note:        one or two sentences of flavor / advice shown with the challenge
